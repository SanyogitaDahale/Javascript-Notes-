#DOM - Document Object Model
DOM allows javascript to access, change, add or remove HTML elements and Css styles on a webpage.
DOM is basically tree like structure.
Ex.
HTML Code --> DOM Tree (converts html into objects arranged like tree, JS can access the dom)  --> Javascript Manipulates the tree--> Webpage changes.

## Add Elements in HTMl -
1) appendChild method to add element, to add we have to first create child for this we have 'createElement'. Whenever we use append child, child always added at the end of parent tag.

Ex. run these on console
let fhead = document.createElement('h1')
fhead
fhead.textContent = "Hello JI"
let bodyTag = document.querySelector('body')

bodyTag

2) insertAdjacentElement()
we need to know two things in it that what position we want to insert and what html content we want to insert.
position - before begin, after begin, before end, after end.
Ex. Run these in Console
let mydiv = document.querySelector('mydiv')
mydiv
let newElement = document.createElement('span')
newElement
newElement.textContent = "This is me Sanyogita"
newElement

mydiv.insertAdjacentElement('beforebegin', newElement)
mydiv.insertAdjacentElement('afterbegin', newElement)
mydiv.insertAdjacentElement('beforeend', newElement)
mydiv.insertAdjacentElement('afterend', newElement)

### - Now to Change CSS - ###
.Changing CSS - external CSS, inline CSS(more priority), Internal CSS.
Properties :
1) Style, can do get and set, Cannot set Multiple inline styles using style.
EX.
let paraElement = document.getElementById('spara')
paraElement
console.log(paraElement.style)
paraElement.style.background = 'blue'

2) .CSSText, get and set inline styles, Most importantly multiple inline styles can be set using CSSText.
let secondElement = document.getElementById('sdiv')
secondElement
secondElement.cssText
secondElement.style.cssText // get
secondElement.style.cssText = "background-color: black; color:White"

3) .SetAttribute(), The JavaScript setAttribute() method updates the value of an existing attribute on a specified HTML element or adds a new one if it does not exist.

EX. Changing image source
const image = document.querySelector('img');
image.setAttribute('src', 'logo.png');

Ex. Disabling a form button
const button = document.querySelector('#submit-btn');
button.setAttribute('disabled', '');

Ex. Adding a custom data attribute
const userCard = document.querySelector('.user-card');
userCard.setAttribute('data-user-id', '12345');
