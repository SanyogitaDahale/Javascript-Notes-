## Math Object in JS
Math named object is already available which provied mathamethical operations.

console.log(Math.PI) // 3.14.....
console.log(Math.max(1, 2, 3, 4, 6, 9, 7, 8, 8)) // 9
console.log(Math.min(1, 2, 3, 4, 6, 9, 7, 8, 8)) // 1
console.log(Math.round(1.8)) // 2
console.log(Math.round(1.5)) // 2
console.log(Math.round(1.4)) // 1
// floor will print smallets integer before number
console.log(Math.floor(1.5)) // 1
// abs is absolute value - which will convert -ve value into +ve.
console.log(Math.abs(5))
console.log(Math.abs(-5))
// randome will provide u any number from 0 to 1
console.log(Math.random())
// for square root
console.log(Math.sqrt(5))
// for Power
console.log(Math.pow(2, 10))
